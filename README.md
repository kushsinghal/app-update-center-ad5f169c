# DealLoot — App Update Center

Deal finder + Control Room. Data is stored in MongoDB; the site runs as one Node service on Render.

## Deploy on Render
1. Push this code to GitHub, then in Render choose **New → Blueprint** and pick the repo (uses `render.yaml`).
2. Fill in when asked:
   - `MONGO_URL` — your MongoDB Atlas connection string (Atlas → Network Access must allow `0.0.0.0/0`).
   - `ADMIN_PASSWORD` — the Control Room password.
   - `APP_URL` (on the cron job) — your web service address, e.g. `https://dealloot.onrender.com`.
   `SESSION_SECRET` and `CRON_SECRET` are generated by Render automatically.
3. The cron job `dealloot-scan` triggers a deal scan every 15 minutes.

Manual setup instead of Blueprint:
- Build: `npm install --include=dev && NITRO_PRESET=node-server npm run build`
- Start: `node .output/server/index.mjs`

## Local
Copy `.env.example` to `.env`, fill it in, then `npm install && npm run dev`.
